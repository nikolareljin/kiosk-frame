# MagicMirror Modules

This appliance focuses on a lightweight MagicMirror setup suitable for 32-bit systems.

Recommended modules:
- Default `calendar` module for ICS feeds.
- MMM-GoogleTasks (for Google Tasks).
- MMM-MicrosoftToDo (for Microsoft To Do).

Notes:
- Install modules inside `/opt/appliance/magicmirror/modules` after MagicMirror is installed.
- Keep modules minimal to avoid CPU/memory pressure on Atom-class systems.
- Update `config/config.js` via the web UI to enable or disable modules as needed.
